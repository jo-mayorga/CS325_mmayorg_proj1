# Web Scraper
Simple web scraper that outputs comments on ebay feedback pages to a txt file, written by Jo Mayorga.

## Usage
Prior to running, create an environment using the supplied requirements.yml file.

To run, use 'py project2.py [input txt file] [output file name]'. For instance, 'py project2.py input.txt reviews' will read in links from a file called 'input.txt' and output user comments of pages to various lines in 'reviews_n.txt'.
